# Expert: версия 1.9.0

17 ноября 2026. Исходные три дуэли на 1.8.0 — 0:3; в двух играх были
6 ответов HTTP 503. Cloudflare подтвердил превышение CPU.
[Исходные игры](expert-before.json), [метрики](hosting-1.9.json).

1.9.0 продлевает поиск на два хода в позициях с единственным нашим ходом;
расширение расходует тот же общий бюджет. На Cloudflare 384 основных узла,
на локальном сервере по умолчанию 6400. Проверка ответов соперника — до 192
узлов на корневой ход, самостоятельное продолжение — до 256.

35 тестов прошли. Локальный первый вызов на 6400 узлах — 167.67 мс,
максимум после прогрева — 81.24 мс. 35 проверочных HTTPS-запросов — без ошибок,
максимум 106.97 мс. Все шесть прежних ошибочных позиций по три повтора —
18 успешных ответов, максимум 223.62 мс.

Новая серия на арене ещё выполняется. Критерий лидерборда оценивается отдельно.
