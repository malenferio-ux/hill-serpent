# Expert: версия 1.10.0

Новая версия опубликована для контрольной серии из 11 дуэлей. Результаты будут добавлены после её завершения; победа в серии пока не заявляется.

Конкурирующие фронты достижимости теперь распространяются одновременно: путь не продолжается за спорной клеткой. Учитываются длины голов, время освобождения тела и hazards. Отдельно сохраняется геометрическая проверка собственного пространства, чтобы не принимать тесный карман с достижимым хвостом за безопасное место.

Итоговая локальная проверка против 1.9.2: 39 побед, 24 поражения, 1 ничья на 64 новых парных стартах. Бюджеты обеих сторон — 384 основных узла. Это самоигра, не измерение силы против Expert. [Все локальные варианты](tuning-1.10.json).

36 тестов прошли. Есть независимый послойный эталон расчёта территории, проверка спорного прохода и сохранённые позиции из трёх поражений. [Подробный разбор позиций](expert-loss-analysis-1.9.2.json).

Предыдущая версия получила 2:3. [Все игры и проверки 1.9.2](expert-1.9.2.md).
