# Journeyman: проверка версии 1.8.0

17 ноября 2026 года. Исходная версия 1.7.1 получила 2 победы и 3 поражения.
Все 1797 ходов точно воспроизведены локально при бюджете 512.
У нашей змейки ошибок HTTP не было, у соперника было по одному таймауту в каждой игре.
Матчи и ошибки сохранены в `journeyman-before.json`.

Новая оценка считает связную область, до которой голова может дойти без прохода
через клетки, которые раньше контролирует соперник. Равная длина делает
одновременный вход небезопасным. Это эвристика, а не доказательство выживания.
Поиск на хостинге остаётся 512 узлов, бюджет защитных проверок не изменён.

Подбор: 20:12 против прежней версии на 32 парных стартах с весом 0.5;
отдельная выборка — 36:28 на 64 новых стартах. Самоигра не является проверкой
против эталона курса. Два других подхода (продление вынужденных ходов и
оценка карманов через точки сочленения) не дали достаточного улучшения.

Публикация и проверка в настоящих дуэлях ещё выполняются.
