# Ядро дуэлей 1.11.0

Собственный алгоритм из `src/agent.mjs` перенесён в `src/duel.c` и скомпилирован
в WebAssembly. Чужие соревновательные змейки и модели не использовались.
Официальный WASI SDK используется только как компилятор C.

Ядро содержит симулятор стандартной дуэли, конкурентное заполнение пространства,
maximin с итеративным углублением, проверку длинного коридора и ответов соперника.
Для обычных дуэлей без hazards JavaScript передаёт поле в модуль синхронно.
Остальные режимы используют прежний JS. Нет потоков, внешних вызовов и состояния
игры между запросами. Память модуля используется повторно; расчёт не делает `await`.

Поиск сохраняет последнюю полностью законченную глубину. Помимо потолка 40000
узлов, он ограничен счётчиком работы: сканированиями поля и расширениями flood fill.
Это условные операции, не микросекунды и не точное измерение CPU. В облаке лимит
1000000, локально 12000000; максимальная обычная глубина 12, плюс до двух
продлений вынужденных ходов. Два дополнительных ограниченных поиска выживания
сохраняют прежние бюджеты: 256 и 192 на вариант корневого хода.

При одинаковом бюджете проверены 874 оценки позиций, 4938 одновременных переходов
и 438 решений: расхождений ходов, глубины и результатов проверок выживания нет;
максимальное различие оценки от округления — 2.28e-13.
[Результат](wasm-parity-1.11.json). Эти числа относятся к трём проигрышам 1.9.2.
Отдельные автоматические тесты проверяют фикстуры и новые случайные позиции,
параллельные HTTP-запросы и повторяемость при чередовании разных полей.

Для обычного `npm start` компилятор и npm-зависимости не нужны: готовый
`src/duel.wasm` включён в репозиторий. После изменения C пересоберите бинарный файл:

1. Скачайте [официальный WASI SDK 34](https://github.com/WebAssembly/wasi-sdk/releases/tag/wasi-sdk-34)
   для своей ОС и архитектуры, проверьте опубликованный SHA-256, распакуйте.
2. Запустите:

```sh
WASI_SDK_PATH=/absolute/path/to/wasi-sdk-34.0-arm64-macos sh tools/build-wasm.sh
npm test
npm run bundle
```

[Хеши исходника, бинарного файла и использованного SDK](wasm-build.json).
Компилятор не включён в архив проекта.

Cloudflare получает `dist/pages/_worker.js` вместе с импортируемым `duel.wasm`.
Одиночного вставленного JS-файла для этой версии недостаточно.
Используются [статический импорт Wasm](https://developers.cloudflare.com/workers/runtime-apis/webassembly/javascript/)
и [поддержка модулей Pages](https://developers.cloudflare.com/pages/functions/module-support/).
