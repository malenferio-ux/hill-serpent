## Что изменено

В исходных проигрышах были две проблемы. Cloudflare прерывал некоторые запросы
из-за CPU-лимита: на старой версии шесть HTTP 503 за три игры. В остальных случаях
Expert обычно наращивал преимущество в длине, отрезал выход и выигрывал концовку.

С версии 1.9.0 основной бюджет Cloudflare для дуэлей явно ограничен 384 узлами;
проверка ответов соперника — 192 узлами на корневой ход. Бесплатный хостинг сохранён.
[Подтверждение CPU-ошибок](hosting-1.9.json), [18 повторов проблемных запросов](expert-retried-errors.json).

В 1.9.1 усилена оценка роста и еды. В 1.9.2 поиск продлевает ветвь, если на границе
обычной глубины **у любой из двух змеек остался единственный вариант продолжения**.
Раньше учитывался только наш вынужденный ход. Это позволяет оценить продолжение
вынужденного маршрута соперника, а не завершать расчёт перед ним.
На каждой ветви разрешены не более двух дополнительных шагов, каждый расходует
прежний общий бюджет. Сохраняется последняя полностью рассчитанная глубина.

Код собственного алгоритма; исходники чужих соревновательных змеек не использовались.

## Проверки 1.9.2

35 тестов прошли. Продлённый поиск сравнивается с независимым полным деревом без
альфа-бета-отсечений; тест отдельно требует ветви, где вынужден только соперник.
Все прежние регрессии проверены, в том числе при облачном бюджете 384.

Одна последовательная нить V8 и GC, Apple M4 Pro, Node 26.12.0: 1000 решений по
корпусу из 4353 позиций с шагом 4. Локальный профиль 6400 узлов: холодный первый
вызов 135.04 мс, максимум после прогрева 75.82 мс; облачный профиль 384 узла:
среднее 1.79 мс. [Данные](latency-1.9.2.json). Это не замер CPU Cloudflare и не
гарантия скорости на любом процессоре.

35 локальных HTTP-запросов: без ошибок, максимум 68.46 мс;
[данные](local-http-1.9.2.json). При первой проверке HTTPS один из 35 запросов достиг клиентского таймаута 500 мс;
[первый прогон сохранён](production-smoke-1.9.2-first.json). Повторный прогон после
завершения развёртывания: 35 из 35 без ошибок, максимум 136.08 мс;
[данные](production-smoke-1.9.2.json). Точная причина одиночного таймаута не установлена.
Cloudflare за последние 30 минут показал 3605 успешных запросов и ноль ошибок CPU
или других ошибок; окно включает фоновые рейтинговые игры и несколько 1.9.x версий.
